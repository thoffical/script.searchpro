# Search Pro Addon

![License](https://img.shields.io/badge/license-CC%20BY--NC--SA%204.0-lightgrey)
![Version](https://img.shields.io/badge/version-1.0.2-blue)

A simple search add-on for Kodi that allows users to search for various items and access different functionalities.

## Features

- User-friendly search dialog.
- Quick access to popular add-ons and scripts.
- Easy installation and usage.

## Installation

1. Download the latest release from the [Releases](https://github.com/thoffical/script.searchpro/releases) page.
2. Open Kodi and go to `Add-ons`.
3. Select `Install from zip file` and choose the downloaded file.
4. Once installed, you can find the add-on in the `Add-ons` menu.

## Usage

- Launch the add-on from the `Add-ons` menu.
- Use the search dialog to find items or access various functionalities.
- Follow the prompts to interact with the available options.
